# ARRIVE Guidelines 2.0 Checklist

> **The ARRIVE Guidelines 2.0:** Animal Research: Reporting of In Vivo Experiments.  
> The guidelines consist of two sets: the **Essential 10** (the basic minimum required for reliability assessment) and the **Recommended Set** (items that add crucial context and represent best practice).

---

## Part 1: The ARRIVE Essential 10

These items are the basic minimum to include in a manuscript. Without this information, readers and reviewers cannot assess the reliability of the findings.

| No. | Item Name | Sub-item | Description & Reporting Requirements |
| :---: | :--- | :---: | :--- |
| **1** | **Study design** | **1a** | For each experiment, provide brief details of study design including the groups being compared, including control groups. If no control group has been used, the rationale should be stated. |
| | | **1b** | The experimental unit (e.g. a single animal, litter, or cage of animals). |
| **2** | **Sample size** | **2a** | Specify the exact number of experimental units allocated to each group, and the total number in each experiment. Also indicate the total number of animals used. |
| | | **2b** | Explain how the sample size was decided. Provide details of any *a priori* sample size calculation, if done. |
| **3** | **Inclusion and exclusion criteria** | **3a** | Describe any criteria used for including and excluding animals (or experimental units) during the experiment, and data points during the analysis. Specify if these criteria were established *a priori*. If no criteria were set, state this explicitly. |
| | | **3b** | For each experimental group, report any animals, experimental units or data points not included in the analysis and explain why. If there were no exclusions, state so. |
| | | **3c** | For each analysis, report the exact value of *n* in each experimental group. |
| **4** | **Randomisation** | **4a** | State whether randomisation was used to allocate experimental units to control and treatment groups. If done, provide the method used to generate the randomisation sequence. |
| | | **4b** | Describe the strategy used to minimise potential confounders such as the order of treatments and measurements, or animal/cage location. If confounders were not controlled, state this explicitly. |
| **5** | **Blinding** | — | Describe who was aware of the group allocation at the different stages of the experiment (during the allocation, the conduct of the experiment, the outcome assessment, and the data analysis). |
| **6** | **Outcome measures** | **6a** | Clearly define all outcome measures assessed (e.g. cell death, molecular markers, or behavioural changes). |
| | | **6b** | For hypothesis-testing studies, specify the primary outcome measure, i.e. the outcome measure that was used to determine the sample size. |
| **7** | **Statistical methods** | **7a** | Provide details of the statistical methods used for each analysis, including software used. |
| | | **7b** | Describe any methods used to assess whether the data met the assumptions of the statistical approach, and what was done if the assumptions were not met. |
| **8** | **Experimental animals** | **8a** | Provide species-appropriate details of the animals used, including species, strain and substrain, sex, age or developmental stage, and, if relevant, weight. |
| | | **8b** | Provide further relevant information on the provenance of animals, health/immune status, genetic modification status, genotype, and any previous procedures. |
| **9** | **Experimental procedures** | **9a** | **What:** What was done, how it was done, and what was used. |
| | | **9b** | **When:** When and how often. |
| | | **9c** | **Where:** Where (including detail of any acclimatisation periods). |
| | | **9d** | **Why:** Why (provide rationale for procedures). |
| **10** | **Results** | **10a** | Summary/descriptive statistics for each experimental group, with a measure of variability where applicable (e.g. mean and SD, or median and range). |
| | | **10b** | If applicable, the effect size with a confidence interval. |

## Part 2: The Recommended Set

These items complement the Essential 10 and add important context to the study. Reporting the items in both sets represents best practice.

| No. | Item Name | Sub-item | Description & Reporting Requirements |
| :---: | :--- | :---: | :--- |
| **11** | **Abstract** | — | Provide an accurate summary of the research objectives, animal species, strain and sex, key methods, principal findings, and study conclusions. |
| **12** | **Background** | **12a** | Include sufficient scientific background to understand the rationale and context for the study, and explain the experimental approach. |
| | | **12b** | Explain how the animal species and model used address the scientific objectives and, where appropriate, the relevance to human biology. |
| **13** | **Objectives** | — | Clearly describe the research question, research objectives and, where appropriate, specific hypotheses being tested. |
| **14** | **Ethical statement** | — | Provide the name of the ethical review committee or equivalent that has approved the use of animals in this study, and any relevant licence or protocol numbers (if applicable). If ethical approval was not sought or granted, provide a justification. |
| **15** | **Housing and husbandry** | — | Provide details of housing and husbandry conditions, including any environmental enrichment. |
| **16** | **Animal care and monitoring** | **16a** | Describe any interventions or steps taken in the experimental protocols to reduce pain, suffering and distress. |
| | | **16b** | Report any expected or unexpected adverse events. |
| | | **16c** | Describe the humane endpoints established for the study, the signs that were monitored and the frequency of monitoring. If the study did not have humane endpoints, state this. |
| **17** | **Interpretation / scientific implications** | **17a** | Interpret the results, taking into account the study objectives and hypotheses, current theory and other relevant studies in the literature. |
| | | **17b** | Comment on the study limitations including potential sources of bias, limitations of the animal model, and imprecision associated with the results. |
| **18** | **Generalisability / translation** | — | Comment on whether, and how, the findings of this study are likely to generalise to other species or experimental conditions, including any relevance to human biology (where appropriate). |
| **19** | **Protocol registration** | — | Provide a statement indicating whether a protocol (including the research question, key design features, and analysis plan) was prepared before the study, and if and where this protocol was registered. |
| **20** | **Data access** | — | Provide a statement describing if and where study data are available. |
| **21** | **Declaration of interests** | **21a** | Declare any potential conflicts of interest, including financial and non-financial. If none exist, this should be stated. |
| | | **21b** | List all funding sources (including grant identifier) and the role of the funder(s) in the design, analysis and reporting of the study. |

## Detailed Interactive Checklist

### The ARRIVE Essential 10

#### 1. Study Design
- [ ] **1a. Comparison Groups:** Specify experimental and control groups. (If no control, state rationale).
- [ ] **1b. Experimental Unit:** Clearly define unit of analysis (e.g., individual animal, cage, or litter).

#### 2. Sample Size
- [ ] **2a. Numbers Used:** Report exact number of experimental units per group, per experiment, and total animals used.
- [ ] **2b. Sample Size Determination:** Detail calculation/method used to determine sample size (*a priori* power calculation).

#### 3. Inclusion and Exclusion Criteria
- [ ] **3a. Pre-established Criteria:** Detail *a priori* criteria for animal/data inclusion or exclusion (or state none were set).
- [ ] **3b. Excluded Animals/Data:** Explain reasons for any exclusions across groups (or state no exclusions).
- [ ] **3c. Exact n Numbers:** Report exact sample size (*n*) for each group in every statistical analysis.

#### 4. Randomisation
- [ ] **4a. Sequence Generation:** State whether groups were randomised and describe the generation method.
- [ ] **4b. Confounder Control:** Detail strategies to minimize bias (e.g., cage position, order of treatment/testing).

#### 5. Blinding
- [ ] **5. Masking Across Stages:** State whether investigators were blinded during allocation, experiment conduction, outcome assessment, and analysis.

#### 6. Outcome Measures
- [ ] **6a. Clear Definitions:** Define all primary and secondary endpoints/outcomes measured.
- [ ] **6b. Primary Outcome:** Explicitly specify the primary outcome measure used to determine sample size.

#### 7. Statistical Methods
- [ ] **7a. Analytic Approach & Software:** Specify statistical tests and software packages/versions used.
- [ ] **7b. Assumption Verification:** State methods used to test distributional assumptions and actions taken if violated.

#### 8. Experimental Animals
- [ ] **8a. Animal Characteristics:** Report species, strain, substrain, sex, age/developmental stage, and weight.
- [ ] **8b. Provenance & Health:** Detail vendor/source, health/immune status, genetic modifications, and prior procedures.

#### 9. Experimental Procedures
- [ ] **9a. What & How:** Exact description of procedures, materials, reagents, and equipment.
- [ ] **9b. When:** Timing, frequency, and duration of interventions.
- [ ] **9c. Where:** Experimental setting and acclimatisation periods.
- [ ] **9d. Why:** Scientific rationale for selected procedures.

#### 10. Results
- [ ] **10a. Descriptive Statistics:** Report measures of central tendency and variability (e.g., mean ± SD, median & IQR/range).
- [ ] **10b. Effect Sizes:** Report effect sizes accompanied by confidence intervals where appropriate.

### The Recommended Set

#### 11. Abstract
- [ ] Provide an accurate, comprehensive summary: objectives, species/strain/sex, methods, key findings, and conclusions.

#### 12. Background
- [ ] **12a. Context:** Provide scientific background, rationale, and context for the study design.
- [ ] **12b. Translational Relevance:** Explain suitability of the animal model and its relevance to human biology.

#### 13. Objectives
- [ ] State clear primary research questions, objectives, and specific hypothesis being tested.

#### 14. Ethical Statement
- [ ] Name ethical review committee/IACUC, provide approval/license/protocol numbers, or state justification if exempt.

#### 15. Housing and Husbandry
- [ ] Specify housing conditions: cage type, bedding, light cycle, temperature, humidity, diet, water, and environmental enrichment.

#### 16. Animal Care and Monitoring
- [ ] **16a. Welfare Steps:** Describe welfare interventions taken to minimize pain, suffering, and distress.
- [ ] **16b. Adverse Events:** Document expected or unexpected adverse events and responses.
- [ ] **16c. Humane Endpoints:** State humane endpoints, clinical signs monitored, and monitoring frequency.

#### 17. Interpretation / Scientific Implications
- [ ] **17a. Synthesis:** Interpret results against study hypotheses, existing theory, and prior literature.
- [ ] **17b. Limitations:** Address study limitations, sources of bias, model limitations, and precision bounds.

#### 18. Generalisability / Translation
- [ ] Discuss generalisability of findings across other species/conditions and translational relevance to human biology.

#### 19. Protocol Registration
- [ ] State whether a study protocol was registered *a priori*, citing registry name and accession/identifier.

#### 20. Data Access
- [ ] Provide data availability statement with DOI/repository link or conditions for data sharing.

#### 21. Declaration of Interests
- [ ] **21a. Conflicts of Interest:** Declare potential financial and non-financial conflicts of interest (or declare none).
- [ ] **21b. Funding & Role:** Disclose funding sources, grant numbers, and the funder's role in the study.
