## Detailed Interactive Checklist

### Title and Abstract
- [ ] **Item 1:**
  - [ ] Information on how units were allocated to interventions.
  - [ ] Structured abstract format followed.
  - [ ] Target population or study sample clearly specified.

### Introduction
- [ ] **Item 2. Background:**
  - [ ] Scientific background and rationale explained.
  - [ ] Theories underpinning behavioral intervention design described.

### Methods
- [ ] **Item 3. Participants:**
  - [ ] Eligibility criteria across recruitment levels (cities, clinics, subjects).
  - [ ] Method of recruitment and systematic sampling details.
  - [ ] Recruitment setting described.
  - [ ] Settings and physical locations of data collection reported.
- [ ] **Item 4. Interventions:**
  - [ ] Content (what was given).
  - [ ] Delivery method (how given).
  - [ ] Unit of delivery (individual vs. group).
  - [ ] Deliverer background and credentials.
  - [ ] Setting where delivered.
  - [ ] Exposure quantity, frequency, and duration.
  - [ ] Overall time span to deliver intervention to each unit.
  - [ ] Strategies to increase compliance/adherence (e.g., incentives).
- [ ] **Item 5. Objectives:**
  - [ ] Specific research objectives and hypotheses formulated.
- [ ] **Item 6. Outcomes:**
  - [ ] Primary and secondary outcome definitions.
  - [ ] Data collection methods and quality enhancement protocols.
  - [ ] Measurement instrument validity (psychometric/biometric properties).
- [ ] **Item 7. Sample Size:**
  - [ ] Determination rationale (e.g., power calculations).
  - [ ] Interim analysis plans and formal stopping rules.
- [ ] **Item 8. Assignment Method:**
  - [ ] Unit of assignment identified.
  - [ ] Assignment procedures and restrictions (blocking, stratification, minimization).
  - [ ] Bias reduction methods for non-random design (e.g., matching).
- [ ] **Item 9. Blinding (Masking):**
  - [ ] Masking status for participants, deliverers, and outcome assessors.
  - [ ] Methods used to implement and test blinding integrity.
- [ ] **Item 10. Unit of Analysis:**
  - [ ] Smallest unit of analysis defined.
  - [ ] Analytical adjustments made if unit of analysis differs from assignment unit.
- [ ] **Item 11. Statistical Methods:**
  - [ ] Group comparisons for primary outcomes (including clustering/correlated data).
  - [ ] Secondary, subgroup, and adjusted analyses.
  - [ ] Missing data handling/imputation methods.
  - [ ] Statistical software packages and versions specified.

### Results
- [ ] **Item 12. Participant Flow:**
  - [ ] Participant flow diagram provided.
  - [ ] Screening, eligibility, refusal, and enrollment numbers.
  - [ ] Allocation and intervention exposure numbers.
  - [ ] Follow-up completion and loss-to-follow-up numbers by group.
  - [ ] Final analyzed sample sizes by group.
  - [ ] Documented protocol deviations with rationale.
- [ ] **Item 13. Recruitment:**
  - [ ] Specific dates for recruitment and follow-up intervals.
- [ ] **Item 14. Baseline Data:**
  - [ ] Baseline demographic and clinical variables per group.
  - [ ] Study-specific disease prevention characteristics.
  - [ ] Attrition comparison (those lost vs. retained).
  - [ ] Study sample comparison with broader target population.
- [ ] **Item 15. Baseline Equivalence:**
  - [ ] Assessment of baseline balance across groups.
  - [ ] Statistical adjustments applied for observed baseline imbalances.
- [ ] **Item 16. Numbers Analyzed:**
  - [ ] Explicit denominators reported for all outcomes.
  - [ ] Clarification of Intention-to-Treat (ITT) or handling of non-compliers.
- [ ] **Item 17. Outcomes and Estimation:**
  - [ ] Effect size estimates and 95% confidence intervals for all endpoints.
  - [ ] Complete reporting of null and statistically non-significant findings.
  - [ ] Mediation or causal pathway test findings reported.
- [ ] **Item 18. Ancillary Analyses:**
  - [ ] Reporting of subgroup/exploratory analyses explicitly labeled.
- [ ] **Item 19. Adverse Events:**
  - [ ] Systematic accounting of unintended effects or harms per group.

### Discussion
- [ ] **Item 20. Interpretation:**
  - [ ] Synthesis considering bias, imprecision, and study limits.
  - [ ] Mechanism of action / causal pathways analyzed.
  - [ ] Implementation fidelity, barriers, and facilitators discussed.
  - [ ] Scientific, clinical, and policy relevance stated.
- [ ] **Item 21. Generalizability:**
  - [ ] External validity discussed in relation to sample, context, and protocol.
- [ ] **Item 22. Overall Evidence:**
  - [ ] Interpretation framed within current literature and theoretical frameworks.
